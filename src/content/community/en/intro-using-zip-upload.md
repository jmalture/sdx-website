## What ZIP Upload is good for

- **Documents for a review:** calculations, permits, contracts and expert reports as one package in the project area.
- **Maintenance reports from several sites** that arrive regularly as a ZIP.
- **Print data** going to a print shop as a bundle, or coming back from it.
- **Project templates:** a ZIP with empty folders (plans, reports, photos, contracts) gives every new project the same structure.
- **Closing and archiving:** the documentation of a finished project in one structured place.

## Good to know

- **Only .zip.** Other archive formats are not accepted.
- **Same limits as a normal upload.** Large archives with many files are possible.
- **Protected:** SDX unpacks ZIP files with a secure implementation that blocks so-called ZIP bombs.
- **Updates:** when you import an updated ZIP into the same folder, files with the same name are replaced and keep their permissions, new files are added and nothing is deleted.
